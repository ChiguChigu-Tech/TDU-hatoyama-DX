# TDU Hatoyama DX

> [!IMPORTANT]
> 本リポジトリは、大学の授業で制作した過去のチーム開発作品です。  
> 現在は開発・保守を終了しており、掲載情報は2023年の制作当時のものです。

東京電機大学の鳩山キャンパスに関する情報をまとめ、学生が必要な情報へアクセスしやすくすることを目的に制作した学内向けWebサイトです。

## 制作概要

- 制作時期：2023年
- 授業：情報デザイン総合演習
- 制作形態：3名によるチーム開発
- 対象：鳩山キャンパスを利用する学生・教職員
- 開発状況：完成済み・保守終了

## 解決しようとした課題

鳩山キャンパスでは、施設、食堂、研究室、教室利用状況などの情報が複数の場所に分散していました。

そこで、キャンパス生活に必要な情報を一つのWebサイトへまとめ、学生が情報を探す負担を軽減することを目指しました。

## 主な機能

- トップページとスライドショー
- 食堂・カフェメニューの掲載
- 1号館から12号館までの施設紹介
- 各学系・研究室の紹介
- 曜日・時限・号館による教室利用状況検索
- お問い合わせ案内ページ
- 管理者ログイン画面のモックアップ
- スマートフォン向けナビゲーション

## 使用技術

### Design template

一部の画面構成にはTemplate-PartyのWebテンプレートを使用し、本プロジェクト向けにページ構成・デザイン・機能を変更しています。

## 教室利用状況検索について

教室利用状況検索では、PHPを利用して現在時刻を取得し、曜日・時限・号館に対応する教室情報を表示します。

ただし、教室情報は制作当時の時間割を基にした固定データです。現在の教室利用状況をリアルタイムで取得する機能ではありません。

## ログイン画面について

ログイン画面は管理者機能のUIを検討するためのモックアップです。

以下の機能は実装されていません。

- ユーザー認証
- パスワード照合
- データベース連携
- 権限管理
- セッション管理

## 起動方法

静的なページだけを確認する場合は、`index.html`をブラウザで開きます。

PHPを含むページを確認する場合は、リポジトリのルートディレクトリで次を実行します。

```bash
php -S localhost:8000
```

起動後、ブラウザで `http://localhost:8000/index.html` を開きます。
